## How to Get Listed

1. **Find a valid security vulnerability** in ai-trading-website
2. **Report it responsibly** via [GitHub Security Advisories](https://github.com/casalenamajyestik/ai-trading-website/security/advisories/new) or email to security@ai-trading-website.com
3. **We'll verify and fix** the issue
4. **You'll be credited** here (with your permission)

## Recognition Levels

| Level | Criteria |
|-------|----------|
| 🥇 **Critical** | RCE, Auth bypass, Data exposure, SQLi |
| 🥈 **High** | XSS (stored/reflected), CSRF, Privilege escalation |
| 🥉 **Medium** | IDOR, Info disclosure, Logic flaws |
| 🏅 **Low** | CSP bypass, Rate limit bypass, Minor info leak |

## Rules

- **No public disclosure** until we've had 90 days to fix (or agree on timeline)
- **No testing on production data** - use test accounts only
- **No automated scanning** without permission
- **No social engineering** or phishing attempts
- **Scope**: *.ai-trading-website.com, api.ai-trading-website.com, GitHub repo

## Out of Scope

- Issues in third-party services (Supabase, Vercel, Binance API)
- Social engineering/phishing
- Physical attacks
- DoS/DDoS (handled by Vercel)
- Missing security headers on non-critical pages
- Self-XSS requiring user interaction
- Issues requiring compromised credentials
